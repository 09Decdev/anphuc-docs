SC-40 — Admin Dashboard ​

ADMIN Route: /admin/dashboard Nguồn: docs/05 §3 SC-40..49 · docs/02 FR-STAT-01/02 · docs/01 §3 North Star · docs/08 BR-ADM-03

Ai xem màn này: Quản trị viên (guard ADMIN 🛡, layout riêng — không lẫn menu user, docs/05 §2). Đây là màn đáp của admin mỗi ca làm việc. Mục đích: trả lời 3 câu hỏi trong 5 giây — (1) tiền chảy chưa (GMV North Star), (2) có gì đang quá hạn SLA không, (3) queue nào cần mở ngay. Read-only: mọi xử lý đi qua link sang queue tương ứng (SC-41/42/47). Ví dụ số dùng trong bản vẽ: "bây giờ" 10/10/2026 14:31 (GMT+7) · admin Minh (ADMIN) · GMV 30 ngày 5.850.000.000 ₫ (3 đơn COMPLETED, Σ giá trúng) · phí thu 116.250.000 ₫ · SLA quá hạn: 1 KYC + 1 tin + 2 cọc manual (khớp queue SC-41/42/47) · phiên LIVE DGA-2026-0001 căn CT2-A18.05.

Chú thích hành vi (trace: docs/02 FR-STAT · docs/01 §3 · docs/08 BR-ADM)
  1. 1Nguồn: `GET /admin/stats/overview?from=&to=` (endpoint 62) — SQL aggregate, cache 5 phút; luôn hiện dòng "cập nhật lúc HH:mm (GMT+7)" để admin không tưởng số liệu realtime. Nút refresh tay = gọi lại kèm bypass cache. Filter from/to áp cho mọi card "30 ngày". FR-STAT-01
  2. 2GMV là North Star (docs/01 §3): tổng giá trị settlement orders COMPLETED — card đặt ĐẦU TIÊN, viền accent đậm, số to nhất màn. KPI G1–G6 còn lại hiện dạng small trong card liên quan, không cạnh tranh thị giác với GMV. docs/01 §3 FR-STAT-01
  3. 3Alert SLA quá hạn: chỉ hiện khi count > 0; nền danger-soft, count = tổng 3 loại hạn (KYC 48h · tin 24h · cọc manual 2h giờ làm việc). Mỗi nút mở thẳng queue tương ứng (SC-41/42/47) — alert không có hành động tại chỗ, dashboard là read-only. Số liệu alert khớp badge đỏ trong từng queue (một nguồn SLA). BR-ADM-03 BR-PAY-04 FR-STAT-01
  4. 4Audit preview: 10 dòng mới nhất từ `GET /admin/audit-logs` (62) — gồm cả actor `system` (job/anti-snipe). Dashboard read-only nên KHÔNG ghi audit từ màn này; append-only, xem đầy đủ ở SC-49. BR-ADM-01/02
  5. 5Export CSV mở menu entity (listings · auctions · orders · users) theo filter hiện hành — `GET /admin/export/{entity}?filters`, giới hạn 50k dòng; đang sinh file → toast info "Đang tạo file — trình duyệt sẽ tự tải khi xong". FR-STAT-02
  6. 6Card click được (trừ GMV/subscription): user mới → SC-48 · tin theo trạng thái → SC-42 · phiên → SC-44/46 · đơn PENDING → SC-47 · SLA đỏ → queue quá hạn (deeplink filter `sla=over`). Hover có affordance, không cần tooltip dài. docs/05 §3 SC-40..49
  7. 74 trạng thái: Loading = 8 khối skeleton cỡ card + 3 khối queue (số không flash 0); Error = `wf-error-box` + traceId + "Thử lại" (không cache-stale âm thầm — nếu trả cache cũ phải dán nhãn "dữ liệu lúc HH:mm"); Data = mục 1; Empty (hệ thống mới) = các card hiện 0 + note "Chưa có giao dịch — seed dự án trước (SC-43)". docs/05 §1.4
  8. 8Card phiên LIVE: badge `live` nhấp nháy tái dùng từ SC-06; số trong card là cache 5 phút (xấp xỉ) — click → SC-46 monitor realtime. Countdown "hạn thanh toán gần nhất" dùng offset giờ server (`X-Server-Time`), không tin đồng hồ máy khách. docs/06 §1
