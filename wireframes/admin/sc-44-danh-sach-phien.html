SC-44 — Danh sách phiên đấu giá (admin) ​

ADMIN Route: /admin/dau-gia Nguồn: docs/05 §3 (SC-40..49) · docs/06 endpoints 54–58 · docs/08 BR-AU · docs/03 UC-11

Ai xem màn này: ADMIN vận hành đấu giá (Ops An Phuc). Đây là "trung tâm điều khiển" mảng đấu giá: xem toàn bộ phiên theo trạng thái, tạo phiên mới (SC-45), công bố, hủy, và nhảy vào monitor phiên LIVE (SC-46). Mục đích: DataTable server-side + tabs theo state machine auctions.state; hành động nguy hiểm (cancel) luôn đi qua modal xác nhận có lý do bắt buộc; mọi mutation → toast + audit log. Ví dụ số dùng trong bản vẽ: phiên LIVE DGA-2026-0001 (auc_01J9X3K8M2) — căn CT2-A18.05 dự án NOXH HP-380, giá khởi điểm 1.800.000.000 ₫, bước giá 18.000.000 ₫ (1%), 7 người tham gia ACTIVE.

Chú thích hành vi (trace: docs/05 §3 · docs/08 §4/§10.2 · docs/06 endpoints 54–58)
  1. 1Tabs = state machine auctions.state (DRAFT → PUBLISHED → IN_PROGRESS → AWARDED/FAILED, CANCELLED terminal); count trong nhãn tab lấy từ metadata API. Tab sync URL ?state= — shareable, reload giữ nguyên. docs/07 §2.9 docs/08 §10.2
  2. 2DataTable server-side (pattern SC-40..49): GET /admin/auctions?state= + page/limit; đổi tab/sort/page đều refetch, không lọc client. Đang fetch → skeleton 8 dòng (mục 3). docs/05 §3 endpoint 54
  3. 3Badge màu theo enum: DRAFT muted · PUBLISHED info · IN_PROGRESS live (nhấp nháy đỏ) · AWARDED ok · FAILED warn · CANCELLED muted. IN_PROGRESS luôn được sort lên đầu trong tab "Tất cả" để Ops không bao giờ bỏ sót phiên đang chạy. docs/07 §3
  4. 4Click dòng: IN_PROGRESS → SC-46 monitor; DRAFT → SC-45 (form sửa); PUBLISHED → SC-45 chế độ xem — khóa sửa khi đã có registration ACTIVE (409 AUCTION_LOCKED, cọc đã thu theo cấu hình cũ); AWARDED/FAILED/CANCELLED → SC-46 read-only (feed đã khóa + kết quả). UC-11 AF-1 BR-AU-09
  5. 5"Tạo phiên" → SC-45 (/admin/dau-gia/create). Chỉ ADMIN tạo/vận hành phiên — v1 seller không tự mở. BR-AU-01 FR-AU-01
  6. 6Hủy chỉ khả thi khi DRAFT/PUBLISHED — nút Hủy KHÔNG render ở các state khác (IN_PROGRESS server trả 409 AUCTION_CANNOT_CANCEL). Click → modal mục 2, lý do bắt buộc. BR-AU-19 FR-AU-10 endpoint 58
  7. 7Công bố (publish): server check BR-AU-03 (notice ≥ 7 ngày trước start) — thiếu → 422 NOTICE_TOO_SHORT, toast đỏ đúng message server; đạt → tin LISTED→RESERVED, phiên hiện public (SC-05), mở đăng ký. Toast + audit AUCTION_PUBLISH. FR-AU-02 endpoint 57
  8. 81 tin = 1 phiên đang sống (partial unique state NOT IN FAILED/CANCELLED): tạo phiên cho tin đã có DRAFT/PUBLISHED/IN_PROGRESS → 409, form SC-45 loại tin đó khỏi dropdown ngay từ đầu. BR-AU-02
  9. 9Xuất CSV theo filter hiện hành (tab + page query), giới hạn 50k dòng; toast info khi file sẵn sàng. FR-STAT-02 endpoint 62
  10. 10Mọi mutation (publish/cancel) → toast + audit log ghi actor, action, entity, diff (kèm reason), ip, traceId — xem lại tại SC-49. Không có ngoại lệ. BR-ADM-01 FR-ADM-04

3. Trạng thái rỗng / loading / lỗi (quy tắc 4-state) ​

LOADING — SKELETON
Skeleton tabs + 8 dòng bảng; giữ nguyên khung để không nhảy layout.
EMPTY — TAB DRAFT TRỐNG
Chưa có phiên nháp nào
Tạo phiên từ một tin đang LISTED — hệ thống tự kiểm tra điều kiện công bố (≥ 7 ngày).
+ Tạo phiên đầu tiên → SC-45
Tab khác rỗng (vd CANCELLED): cùng khung, bỏ CTA, chỉ hiện "Không có phiên nào ở trạng thái này".
ERROR — KHÔNG LOAD ĐƯỢC
Không tải được danh sách phiên
Kiểm tra kết nối và thử lại. Nếu lỗi kéo dài, báo kỹ thuật kèm mã truy vết:
traceId: 4f2a9c1e-77b0-4d3a
Thử lại
Chú thích
  1. 144 trạng thái bắt buộc cho mọi màn dữ liệu admin: Loading (skeleton) → Empty (CTA nếu là điểm khởi tạo) → Error (message + traceId rút gọn + Thử lại) → Data (mục 1). docs/05 §1.4
  2. 15Empty của tab DRAFT là cơ hội hành động (CTA tạo phiên) — các tab còn lại rỗng chỉ là thông tin, không CTA để tránh nhiễu. docs/05 §3
