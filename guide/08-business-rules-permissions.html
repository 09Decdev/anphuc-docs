Business Rules + Permission Matrix — AnPhucRealEstate v1 ​

Status: In Review — Author: Alex (PM) + Pháp chế (chờ sign-off OQ-4) — Updated: 2026-10-10 — v1.4 (M-003 media foundation: BR-IDT-08 storage PUBLIC/PRIVATE + presigned TTL, §9 thêm row files 64/65/66 + ảnh dự án 67/68, BR-ADM-01 ghi nhận PROJECT_IMAGE_ADD/PROJECT_IMAGE_REMOVE) — v1.3 (US-HS-01 bổ sung DELETE: BR-ADM-01 ghi nhận PROJECT_DELETE — hard delete, diff {before}; §9 matrix đổi thành tạo/sửa/xóa dự án) — v1.2 (M-002/US-HS-01 backend: BR-ADM-01 ghi nhận audit PROJECT_CREATE/PROJECT_UPDATE, §9 thêm row admin dự án endpoint 51) — v1.1 (review pass: thêm BR-ADM-04 reset password ADMIN, đồng bộ BR-PAY-05/BR-AU-17 với F-07/UC-08) Quy tắc sử dụng: developer chỉ implement đúng ID được reference trong story; không tự suy đoán giá trị/ngoại lệ. Giá trị "config" = seed có thể đổi bởi ADMIN (table config nếu cần), giá trị "hard" = enforce trong code. Số liệu đầu tiên là giả định PM để dev triển khai, chờ ban điều hành duyệt (OQ-8) — đổi số không đổi cấu trúc rule.

10.3 auction_registrations.state ​

10.4 settlement_orders.state ​

PENDING →(payment SUCCESS) PAID →(ADMIN confirm) COMPLETED · PENDING →(job payBy) EXPIRED · PAID →(ADMIN cancel+refund) CANCELLED_REFUNDED.

10.5 payments.state ​

INITIATED →(redirect/await) PROCESSING →(webhook/manual) SUCCESS|FAILED · INITIATED|PROCESSING →(job 6h) EXPIRED · SUCCESS →(refund) REFUNDED · webhook amount lệch → RECON_FAILED.

10.6 kyc_applications.state ​

PENDING →(approve) APPROVED | →(reject) REJECTED (terminal per application; resubmit = application mới). users.kyc_status: NONE →(submit) PENDING →(review) APPROVED|REJECTED (mirror mới nhất; resubmit REJECTED→PENDING).

10.7 user_subscriptions.state ​

PENDING →(payment) ACTIVE →(ends_at) EXPIRED · ACTIVE →(mua package khác) SUPERSEDED; cùng package: stays ACTIVE, ends_at++.
