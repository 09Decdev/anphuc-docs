User Stories + Backlog / Task Breakdown — AnPhucRealEstate v1 ​

Status: Ready for Sprint 1 — Author: Alex (PM) — Updated: 2026-10-10 — v1.4 (US-IDT-05 media foundation DONE — endpoints 64/65/66/67/68, storage OQ-3 chốt SeaweedFS; ảnh dự án hiển thị trên card + gallery detail) — v1.2 (US-HS-01 backend DONE — endpoints 11/12/51 + seed + audit, TC-PRJ-01..09; FE admin dự án tách riêng) — v1.1 (review pass: thêm US-ADM-04 reset password, đồng bộ v2 backlog với non-goals docs/01) Cách đọc: Epic → Story (US-<module>-<n>) → Task (BE/FE/QA/Design). 1. North Star & Sprint goal theo milestone ​

  • North Star v1: GMV đấu giá hoàn tất (docs/01 §3).
  • MS1 goal: "Chủ nhà thật đăng được tin được duyệt, khách thật xem được tin" — US nhóm 1xx–4xx.
  • MS2 goal: "1 phiên đấu giá chạy end-to-end với tiền thật" — US nhóm 5xx–6xx.
  • MS3 goal: "Sàn tự kiếm tiền + vận hành đo được" — US nhóm 7xx–0xx.

4. Definition of Done (chung mọi story) ​

  1. Code merge vào main, lint + typecheck xanh.
  2. npm run test:e2e PASS 100%, skipped=0 — điều kiện cứng trước commit theo quy trình dự án (hook require_tests.py; cấm --no-verify, cấm skip test).
  3. Unit tests cho aggregate/state machine (docs/08 §10 transition matrix).
  4. Swagger @SwaggerApiDocument đủ mọi endpoint mới, khớp docs/06; FE đã confirm hợp đồng (comment trong PR).
  5. Story docs/09 TC tương ứng xanh + trace Story → TC → test name trong PR.
  6. Không lệch doc: đổi schema/API/rule → PR update docs/02/06/07/08 cùng lúc (docs/07 §6, docs/08 §12).
  7. PM/QA review AC trước khi đóng story. Backend cần thêm: observability (traceId, log có cấu trúc).
