UI/UX Specification — AnPhucRealEstate v1 (Web) ​

Status: Draft chờ Design Lead — Author: Alex (PM) + Design Lead (Figma TBD) — Updated: 2026-10-09 — v1.1 (review pass: SC-09 thêm link "Quên mật khẩu?" → hướng dẫn CS, đồng bộ tiền/múi giờ/khung giờ với docs/02/08) Figma: link chưa tồn tại — điều kiện bắt buộc trước dev MS1: https://figma.com/<TBD> (OQ-design-1). Quy ước của doc này: mọi màn phải có chú thích hành vi trong Figma, không chỉ hình — khung chú thích dùng nội dung §3/§4 dưới đây (copy nguyên văn ID SC-xx để trace).

1. Nguyên tắc thiết kế ​

  1. Tiếng Việt, văn phong "an toàn & minh bạch" (không màuSale lòe); format tiền 1.250.000.000 ₫, ngày dd/MM/yyyy HH:mm ( múi giờ máy khách, gắn chú "GMT+7").
  2. Mobile-first responsive; breakpoints 360 / 768 / 1024 / 1440; table admin ưu tiên desktop.
  3. Mọi CTA nghiệp vụ phải hiện đủ trạng thái: default / loading (disabled) / success / error — FE dùng component Button với loading prop.
  4. Pattern 4 trạng thái bắt buộc cho mọi màn dữ liệu: Loading (skeleton) → Empty (CTA hướng dẫn) → Error (thông điệp + nút thử lại, kèm traceId rút gọn) → Data.
  5. Form: validate onBlur + onSubmit, message tại field, dùng string từ docs/06 §5 (một nguồn lỗi).
  6. Tiền là thông tin trọng yếu: mọi màn có tiền hiện breakdown từng dòng, không hiện số gộp duy nhất.
  7. Accessibility: contrast AA, focus ring, label cho mọi input, alt text ảnh tin.

4. SC-06 — Phiên đấu giá live (đặc tả chi tiết, màn quan trọng nhất) ​

Layout desktop: trái = feed bid (virtualized), phải = sticky panel {listing summary, countdown, current price, leader badge, bid form}. Mobile: tab Feed / Bid, countdown sticky top. Nguồn dữ liệu v1: polling GET /auctions/{id} + GET /auctions/{id}/bids?cursor= mỗi 5 giây (quyết định v1; WebSocket = v1.1, không phụ thuộc UX). Optimistic UI: bid 201 → chèn ngay dòng "Bạn" màu highlight; nếu poll sau đó không thấy (hiếm, race) → FE refresh toàn bộ feed, log Sentry. Bid form: quick buttons [+step, +2×step, +5×step] + custom input (số, format VND); min = current+step (client calc từ state server, server re-check). Submit → modal xác nhận "Giá: X — không thể rút. Xác nhận?" → POST. Countdown: server time hiệu chỉnh 1 lần (offset = serverDate − clientDate); khi extend anti-snipe → toast đỏ + countdown +60s + dòng hệ thống trong feed "⏱ Phiên kéo dài 60s". Kết thúc: feed khóa (disabled), overlay kết quả: AWARDED (chúc mừng / bạn bị vượt / người TV-XXXX) hoặc FAILED (tin về bán thường, hướng dẫn mua thỏa thuận qua lịch xem). Trạng thái lỗi: 429 → "Chờ 1 giây trước khi bid lại" (disable 1s); 403 (bị đuổi) → overlay "Tài khoản tạm ngưng quyền đấu giá — liên hệ CS"; mất kết nối >15s → banner vàng "Mất kết nối — thử lại", nút bid disable.
