SRS — Software Requirements Specification ​

Dự án: AnPhucRealEstate v1 (không AI) Status: In Review — Author: Alex (PM) cùng Tech Lead (chưa chốt) — Last updated: 2026-10-10 — Version: 1.3 (M-003 media foundation đã implement: OQ-3 chốt SeaweedFS, FR-HS-08 ghi chú contract thật endpoints 64/65/66 + ảnh dự án 67/68) — 1.2 (M-002/US-HS-01 backend đã implement: FR-HS-01 mở rộng đúng field đã giao, FR-ADM-05 ghi nhận seed CLI npm run db:seed:projects) — 1.1 (review pass: đồng bộ prefix ID với docs/07, thêm FR-ADM-06/FR-IDT-07 reset password, FR-HS-08 signed URL media) Chuẩn áp dụng: ánh xạ IEEE 830 thu gọn; yêu cầu có ID ổn định FR-<module>-<nn>; mỗi FR trỏ tới Use Case (docs/03), Business Rule (docs/08), API (docs/06), Data (docs/07), Acceptance (docs/09). Modules: IDT (identity), KYC, HS (housing), ADM (moderation/admin), AU (auction), PAY (payment), PKG (package/subscription), VW (viewing), NTF (notification), STAT (admin stats).

1. Tổng quan hệ thống ​

  • Kiến trúc backend: NestJS 11, Hexagonal (Ports & Adapters), TypeScript strict — theo backend/README.md. Bounded context mới thêm theo 7 bước chuẩn trong README (core entity → outbound port → inbound port → use case+token → persistence adapter → controller+DTO → module).
  • Frontend: Next.js 16 App Router, feature-based (frontend/src/features/<domain>); app/ chỉ render feature; mọi gọi backend qua services/api-client với envelope chuẩn.
  • API envelope: thành công { success, statusCode, message, data, metadata?, timestamp }; lỗi { success:false, ..., error: <ErrorCode>, errors?, traceId }. Controller KHÔNG tự build envelope (Interceptor/Filter lo).
  • Swagger: sinh tự động tại /api/v1/docs qua @SwaggerApiDocument — docs/06 là hợp đồng, code phải khớp.
  • Client khác: Flutter mobile (repo `mobile/) — chỉ tiêu thụ API, không GA trong v1.

5. Ràng buộc hệ thống ​

  1. TypeScript strict; ValidationPipe global whitelist + forbidNonWhitelisted — request thừa field → 400.
  2. Không được đổi envelope response (api.response.interceptor) — FE phụ thuộc.
  3. ErrorCode enum là nguồn lỗi duy nhất; thêm mã mới theo section context.
  4. Controller mỏng: nhận DTO → inbound port (token DI); nghiệp vụ trong aggregate; transaction tại use case (README backend mục Luật phụ thuộc).
  5. DB/ORM chưa chốt (OQ-1) → docs/07 là logical data model chuẩn, migration do adapter implement; mọi adapter persistence phải thỏa ràng buộc unique/check trong docs/07.
  6. Clock: không dùng Date.now() rải rác — qua ClockPort (đã có pattern providers/) để test fake clock.
  7. Frontend feature mới đặt tại frontend/src/features/{auth,kyc,housing,auction,payment,subscription,viewing,notification,admin}; route nhóm (public), (user), (admin).
  8. Mobile app không nằm trong v1; API giữ contract ổn định để Flutter dùng lại (dio + envelope map đã có).
